# UI 设计与实现

适用于开发 Bot 制作网页、应用界面或改版现有前端。先读取用户给的截图、品牌要求和当前项目代码，区分参考风格与必须保留的真实功能。

1. 找出页面所对应的真实路由、组件、数据和交互。没有实现的功能要明确标出，不做只能看的假按钮。
2. 先确定页面结构、视觉层级、色彩与关键状态。用户要求先看预览时，先交付可查看的预览或截图，得到反馈后再接入正式界面。
3. 在现有技术栈内实现，优先复用项目组件和设计变量。给主要操作、空状态、加载状态和窄屏布局提供可用设计。
4. 运行类型检查、相关测试并实际查看页面；发现文字溢出、错位或操作无响应时修复。交付时说明入口、已实现交互、验证结果和仍需后端支持的部分。

不要把参考图中的品牌、文字和素材直接复制为用户产品；不要把静态预览称为已实现功能。
