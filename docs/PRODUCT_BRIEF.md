- 用户已明确授权制作正式产品、上传 GitHub，并希望完成后安装体验；GitHub 仓库先设为**私有**。
- 四位 Bot 形象已从参考图方向制作成独立素材并接入首页；优先复用现有助手与会话机制。
- 本版 PRD 见 `docs/XUZUO_PRD.md`。当前阶段交接由用户确认并手动切换，不宣称已实现自动全流程上线。

- 用户期望的完整流程是：PRD → 后端 → 前端 → 测试／验收 → 上线。现有产品可接入编码助手，但尚未将这些阶段做成一个有状态、有交付物和验收闸门的产品流程；既有 V1 PRD 主要是界面改版稿，不能冒充全流程需求。
- 用户提供 `ai-product-starter-kit-main.zip`：主要是 `AGENTS.md`、PRD 模板和三份开发／前端／部署手册，依赖外部编码 AI 执行。适合作为流程与验收规则参考，不是可直接接入的运行时模块。其默认云部署路线面向新建 Python／Next.js 项目，不应硬套在现有 Electron／Rust 工程上。
- 用户提供 `agent-blueprint-main.zip`：Python 引擎提供点子／PRD 到方案，以及项目到差距报告。当前 CLI 交付方案和审计报告；真正的产品代码生成是后续任务。`s01`–`s17` 为 Agent 组件参考实现，与现有 AionUi／AionCore 的 Agent、工具、权限、技能等能力存在明显重叠。
- 整包复制或把两个包的 `AGENTS.md` 直接叠到现有工程会造成重复编排、模型配置和权限规则，并引入额外 Python 运行依赖。若进入实现，优先提炼分阶段流程、交付物模板和验收闸门；Blueprint 引擎只在确有必要时作为隔离的可选规划／审计服务评估，不复制其组件库重建现有 Agent 内核。
